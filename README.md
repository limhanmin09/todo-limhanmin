# 임한민의 할 일 목록

브라우저에서 바로 쓰는 귀여운 파스텔 할 일 앱이에요.

**사이트:** https://todo-limhanmin.vercel.app

## 기능

- 할 일 추가, 완료 체크, 삭제
- 할 일 글자를 두 번 클릭해서 고치기 (Enter 저장, Esc 취소)
- 마감일과 시간 정하기 (둘 다 선택), `D-3` / `D-Day` / `지남` 표시
- 마감이 가까운 순서로 정렬, 완료한 일은 맨 아래로
- 🔔 가장 가까운 할 일 알림
- 작성자 이름 적기 (선택)
- 전체 / 진행 중 / 완료 필터와 남은 할 일 개수
- 빈 공간에 재치 있는 문구

## 알아 둘 점

할 일은 브라우저에만 저장돼서 **새로고침하면 전부 지워져요.**

## 사용한 기술

- **HTML, CSS, JavaScript**: 설치나 빌드 없이 바로 실행돼요.
- **Vercel**: GitHub `main` 브랜치에 푸시하면 사이트에 자동으로 배포돼요.
- **Supabase**: 할 일을 저장할 `todos` 표만 준비돼 있고, 앱과는 아직 연결하지 않았어요. 표에는 권한 설정(RLS)이 켜져 있어요.

## 내 컴퓨터에서 실행하기

`index.html`을 더블클릭하면 브라우저에서 열려요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `style.css` | 디자인 |
| `app.js` | 동작 (추가, 완료, 고치기, 정렬, 필터) |
| `.mcp.json` | Claude Code에서 쓰는 Supabase MCP 연결 설정 |
